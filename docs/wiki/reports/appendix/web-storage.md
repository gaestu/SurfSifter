# Web Storage List (Appendix Module)

Lists web storage key-value pairs grouped by origin.

## Purpose
- Provide a complete listing of LocalStorage and SessionStorage entries as supporting evidence.
- Group entries by site origin for readable presentation.

## Inputs
- Local storage and session storage records from browser storage extraction.
- Tags applied to stored site entries.

## Filters and controls
- Site Tags: Multi-select tag filter on stored site artifacts.
- Storage Type: All, Local Storage only, or Session Storage only.

## Output
- List grouped by origin, with each origin showing all stored key-value pairs and storage type indicators (local/session).

## Notes
- Use this appendix when the full web storage would overwhelm the main report sections.
- Only origins with matching storage entries appear in the output.
